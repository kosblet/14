# E-commerce Project

Проект представляет собой ядро интернет-магазина с использованием ООП-подхода. В рамках этого задания реализованы классы `Product` и `Category`, а также их тестирование.

# Интернет-магазин

Этот модуль содержит классы для интернет-магазина:

## Классы

### `Product`
- `name`: название
- `description`: описание
- `price`: цена (приватная)
- `quantity`: количество на складе
- `new_product()`: класс-метод для создания продукта из словаря
- `__add__`: сложение товаров (только одинаковые типы)
- `__str__`: строковое представление

### `Category`
- `name`: название категории
- `description`: описание
- `products`: приватный список товаров
- `add_product()`: добавляет товар, проверяет тип
- `products` (геттер): формирует строку с товарами
- `__str__`: количество продуктов в категории
